# Inicio
## Prerrequisitos
- Tener una cuenta de [Internet Archive](https://archive.org/), para las descargas directas.
- O tener instalado [qBittorrent](https://www.qbittorrent.org/download), para los torrents.
- Recomendación: tener [uBlock Origin](https://ublockorigin.com/) o similar instalado como bloqueador de anuncios, o usar un navegador con un bloquedor de anuncios instalado directamente (Todo pirata debe tener siempre un bloqueador de anuncios instalado)
